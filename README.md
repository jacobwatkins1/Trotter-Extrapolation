# Trotter-Extrapolation
This repo contains code and data associated to the publication ["Exponentially Reduced Circuit Depths Using Trotter Error Mitigation"](https://arxiv.org/abs/2408.14385), particularly the Heisenberg chain system of Sec. 7.3.

Final data used in the publications may be generated with the Jupyter Notebook "Richardson_and_Polynomial_Comparison.ipynb". The associated data and plots can be found under Graphs -> For Paper.

This repo is archived via Zenodo.
